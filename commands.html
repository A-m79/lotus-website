🚀 Getting started
🪷
/lotus setupAnalyzes and automatically configures/repairs Lotus's security infrastructure — category, logs/alerts/quarantine channels, and the verification gate.
Administrator

/lotus config punishmentSets the punishment applied upon detection

/lotus config statusDisplays Lotus's current configuration
Administrator

/lotus config activitylogsEnable/disable message edit/delete + join/leave logging to the logs channel
